```

10_엉삼_login.html     로그인 / 회원가입 (캔바 p.2·3) — 화면(UI)만 있고 실제 로그인 기능은 없음
```

## JavaScript 없이 구현한 방법
| 기능 | HTML/CSS 기법 |
|---|---|
| 탭 (로그인·아카이빙·동방), 대표 사진 슬라이드, 달력 월 이동, 갤러리 연도 필터 | 숨긴 `<input type="radio">` + `<label for>` + `:checked ~` 선택자 |
| 비품 수량 −/+ | 수량마다 라디오 버튼을 하나씩 두고, −/+ 라벨이 이웃 라디오를 선택. 숫자는 CSS 카운터(`counter()`)로 표시 |
| 타이틀 불 켜기, '모두의 공간이니까요' 회전 | 숨긴 체크박스 + `:checked` + `@keyframes` / `transition` |
| 교육자료 드라이브 폴더 목록 | `<iframe>`으로 구글 드라이브 폴더 보기 화면을 끼워 넣음 |
| 사진 크게 보기 | `<a href="#photo-…">` + `:target` |
| 달력 일정 말풍선 | `data-tip` 속성 + `::before { content: attr(data-tip) }` |
| 입력 오류 안내 | HTML 검증 속성(`required`, `pattern`, `minlength`) + `:user-invalid` |
| 스크롤하면 헤더 배경 생김, 섹션 떠오름 | CSS 스크롤 애니메이션(`animation-timeline`). 지원하지 않는 브라우저에서는 효과 없이 정상 표시 |
| 갤러리 사진 흐르기, 타임라인·스티커 호버 | `:hover`, `:active`, `animation-play-state` |

## 내용 바꾸는 방법
- **교육자료**: '해커톤 자료집' 구글 드라이브 폴더와 연결되어 있어요. 폴더에 파일을 올리면 사이트의 목록에도 바로 보여요. 단, 폴더 공유 설정이 '링크가 있는 모든 사용자'여야 목록이 보입니다.
- **회의록 링크**: `10_엉삼_archive.html`의 회의록 부분에서 `class="open" href="#"`의 `#`를 드라이브 주소로 바꿉니다.
- **갤러리 사진**: 사진은 `res/` 폴더에 `연도-영문이름.jpg`로 들어 있어요(예: `2025-hangang-race.jpg`). 같은 이름으로 덮어쓰면 사진만 바뀌고, 새 사진을 추가하려면 `10_엉삼_archive.html`의 갤러리 부분에서 기존 사진 한 줄을 복사해 파일 이름·사진 이름·연도 클래스(`y2025` 등)를 바꾸면 됩니다.
- **비품 기본 수량**: `10_엉삼_room.html`에서 각 비품의 `checked`가 붙은 라디오가 기본 수량입니다.

| 글자 | `#F5F3EE` / 보조 `#D9D9D6` / 캡션 `#A3A3AB` | 제목, 본문, 메뉴 |

| 용도 | 폰트 | 크기 |
|---|---|---|
| 제목 | Gasoek One | 메인 타이틀 44~104px, 섹션 제목 32~52px (화면 폭에 따라 바뀜) |

## 사용자 편의성 고려 요인
1. **반응형 (모바일 우선)**: 360px 휴대폰부터 데스크톱까지 한 화면에 맞춰집니다. 휴대폰에서는 히어로 스티커가 2×2 버튼으로 바뀌고, 카드 목록은 1~2열로 줄어듭니다. 어떤 폭에서도 가로 스크롤이 생기지 않습니다.
2. **메뉴 깊이 최소화**: 상단 메뉴는 아카이빙, 동방 운영, 로그인 3개뿐입니다. 하위 메뉴는 드롭다운 대신 각 페이지 안의 탭으로 처리해서 어떤 내용이든 2번 안에 닿습니다. 메인에서는 바닥 스티커 4개를 누르면 해당 섹션으로 부드럽게 스크롤됩니다.
3. **색 대비**: 본문 크림색과 바탕의 명도 대비는 약 17.7:1, 캡션 회색도 약 7.8:1로 WCAG AA 기준(4.5:1)을 넉넉히 넘습니다. 노랑·주황 버튼 위에는 검정 글자를 써서 대비를 확보했습니다.
4. **터치·키보드 접근성**: 누를 수 있는 요소는 모두 44px 이상입니다. Tab 키를 누르면 노란 포커스 테두리가 보이고, '본문 바로가기' 링크가 있습니다. 탭과 비품 수량은 방향키로도 바꿀 수 있습니다.
5. **상태를 바로 알려 주기**: 입력이 틀리면 칸 바로 아래에 이유가 나오고, 비품이 기준 수량 아래로 떨어지면 '부족' 배지가 뜹니다. 청소를 체크하면 그 줄에 완료 표시가 됩니다.
6. **움직임 배려**: 기기에서 '동작 줄이기'를 켠 사용자에게는 배경 빛, 사진 흐름, 깜빡임 애니메이션이 꺼집니다.

## 한계
- JavaScript가 없어서 로그인은 화면만 있고, 실제로 계정을 확인하지 않습니다. 아카이빙은 로그인 여부와 관계없이 부원용 화면으로 보입니다.
- 비품 수량과 청소 체크는 새로고침하면 처음 값으로 돌아갑니다.
