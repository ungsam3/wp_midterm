# 엉뚱한 사람들 웹페이지 — 관리자 권한표

## 계정 구분

| 역할 | role 값(예시) | 생성 방식 |
|---|---|---|
| 회장 | `president` | 코드에 미리 저장 (회원가입 불가) |
| 부회장 | `vice` | 코드에 미리 저장 (회원가입 불가) |
| 동방관리자 | `manager` | 코드에 미리 저장 (회원가입 불가) |
| 일반 회원 | `member` | 회원가입으로 생성 |

## 기능별 권한

| 페이지 | 기능 | 회장 | 부회장 | 동방관리자 | 일반 회원 | 상태 |
|---|---|:---:|:---:|:---:|:---:|---|
| 교육자료 | 자료 등록 요청 (대기 상태로 등록) | ✅ | ✅ | ✅ | ✅ | 확정 |
| 교육자료 | 등록 요청 승인 / 거절 | ✅ | ✅ | ❌ | ❌ | 확정 |
| 갤러리 | 이미지 삭제 | ✅ | ✅ | ❌ | ❌ | 보류 (팀원 구조 개편 후 재논의) |
| 비품 | 기존 비품 모달의 수량 편집 | ✅ | ❌ | ✅ | ❌ | 확정 |
| 비품 | 새 비품 추가 | ✅ | ❌ | ✅ | ❌ | 보류 (데이터 경로 논의 후) |
| 청소담당 | 조 배정표 이름 칸 편집 | ✅ | ❌ | ✅ | ❌ | 확정 |
| 청소담당 | 체크 초기화 버튼 (관리자에게만 보임) | ✅ | ❌ | ✅ | ❌ | 확정 |
| 청소담당 | 청소 일정표 학기 전환 (2학기 9–12월 ↔ 1학기 4–7월) | ✅ | ❌ | ✅ | ❌ | 확정 |
| 청소담당 | 응원 댓글 삭제 (관리자에게만 삭제 버튼 보임) | ✅ | ❌ | ✅ | ❌ | 확정 |
| 이용규칙 | 규칙 작성 / 수정 | ✅ | ❌ | ✅ | ❌ | 미정 |

## 데이터 저장

| 데이터 | 저장 방식 |
|---|---|
| 회원 목록 (role 포함) | localStorage `users` |
| 로그인한 회원의 역할 | localStorage (예: `role`) |
| 교육자료 (대기 / 승인 상태) | localStorage |
| 비품 수량 수정값 | localStorage (원본은 JSON) |
| 청소 조 배정표 이름 | localStorage |
| 청소 일정표 학기 선택 | localStorage |
| 응원 댓글 | 초기값은 JSON, 추가·삭제는 localStorage |
